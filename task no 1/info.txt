TASK 2: SIMPLE REFLEX AGENT – ROOM TEMPERATURE CONTROL
This Python task models a simple reflex agent for an air-conditioning system. It takes a desired temperature and room sensor information (current temperature and occupancy). Its intended rules select an AC target based on whether the room is occupied and how the current temperature compares with the desired temperature. It also compares the new target with the previous mode to decide whether a command needs to be sent.

Sample rooms in the code:
- Store_room: 30 degrees, occupied
- Bed_room: 12 degrees, occupied
- empty_room: 30 degrees, unoccupied

This task explains that human-like conversation does not by itself prove general intelligence. It discusses the Turing Test, the abilities measured by conversational tests, their limitations, an example of incorrect mathematical reasoning, and a multi-task benchmark for evaluating AI performance.
